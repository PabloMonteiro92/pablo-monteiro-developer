## 🎯 Sobre o Projeto

Portfólio que representa minha transição para a área de **Análise e Desenvolvimento de Sistemas**, destacando:

- Desenvolvimento Front-end com foco em UX/UI
- Automação de processos e otimização
- Código limpo seguindo melhores práticas
- Soluções práticas e inovadoras

## ✨ Funcionalidades

- **Design Responsivo**: Adaptação para todos os dispositivos
- **Animações Fluidas**: Transições suaves na navegação
- **Formulário de Contato**: Integração com EmailJS
- **Galeria de Projetos**: Apresentação interativa dos trabalhos
- **Performance Otimizada**: Carregamento rápido

## 🛠️ Tecnologias

- **HTML5**: Estrutura semântica
- **CSS3**: Design responsivo com Grid/Flexbox
- **JavaScript (ES6+)**: Interatividade e DOM
- **EmailJS**: Envio de emails sem servidor

## 📁 Estrutura

```
portfolio/
├── assets/
│   ├── images/         # Imagens otimizadas
│   └── documents/      # Currículo PDF
├── css/
│   ├── style.css       # Estilos principais
│   └── responsive.css  # Media queries
├── js/
│   ├── main.js         # Lógica principal
│   └── animations.js   # Controle de animações
└── index.html          # Página principal
```

## 🚀 Como usar

```bash
# Clone o repositório
git clone https://github.com/pablo/portfolio.git

# Navegue até o diretório
cd portfolio

# Abra index.html no navegador
# Ou use servidor local:
python -m http.server 8000
```

## 🌐 Deploy
